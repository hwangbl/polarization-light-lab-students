# 偏振光虚拟实验室 · 学生版

学生访问地址：https://hwangbl.github.io/polarization-light-lab-students/

本平台直接由 GitHub Pages 托管，无须登录，打开后即可使用三维光路、仪器操作、偏振模拟、布鲁斯特角测量和实验数据处理功能。

学生可以导出自己的实验数据，以及包含误差条、可选空心散点符号和拟合线的 PNG、SVG 图表。

本仓库仅包含学生平台的压缩运行文件、仪器展示照片和必要字体。课件、教学参考资料原件和完整开发工程未在本仓库公开。网页运行所需的前端文件仍可由浏览器查看。

数据保存在当前浏览器本地，请及时导出并自行保存。仪器模型用于教学演示，模拟读数应与真实实验测量区分。

第三方组件许可证见 THREE-LICENSE.txt 与 KATEX-LICENSE.txt。
